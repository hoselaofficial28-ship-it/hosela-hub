# Hosela Hub

Aplikasi internal Hosela untuk absensi, KPI, izin, notifikasi, penggajian, slip gaji, dan pengelolaan tim.

## Aplikasi aktif

- Frontend produksi: `index.html`, `css/`, `js/`, `assets/`
- Backend aktif: Google Apps Script di `gas/`
- Arsip backend: `gas-backup/`, `gas-paste/`, dan `gas-split/` — jangan dihapus
- Halaman diagnosis: `debug.html` dan `reset.html`

## Rencana clone Supabase

Versi baru akan memakai Supabase sebagai database/backend, sedangkan foto kamera tetap disimpan di Google Drive. Versi lama harus tetap hidup sampai versi baru lolos seluruh uji kesetaraan.

Mulai dari [dokumen handoff](docs/clone-supabase/00-MULAI-DI-SINI.md) dan ikuti instruksi [CLAUDE.md](CLAUDE.md).
